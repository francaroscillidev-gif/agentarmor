## 🚨 Reporting a Vulnerability

The AgentArmor project takes security issues extremely seriously.

If you believe you have found a security vulnerability in AgentArmor (e.g. policy bypass, sandbox escape, DLP leak):
1. **Do not create a public GitHub Issue.**
2. Send an encrypted or direct email to **[francaroscillidev@gmail.com](mailto:francaroscillidev@gmail.com)**.
3. Include detailed steps to reproduce the issue (PoC script, payload, expected vs actual behavior).

We will acknowledge receipt of your vulnerability report within **24 hours** and provide regular status updates until a patch is released.
